# التقرير التشخيصي وخارطة التحول الرقمي

صفحة عربية ثابتة لجمعية النخب العلمية، جاهزة للنشر على GitHub Pages أو Netlify.

## التشغيل

افتح ملف `index.html` مباشرة في المتصفح.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا وارفع محتويات المجلد إلى الفرع `main`.
2. من Settings → Pages اختر Deploy from a branch.
3. اختر الفرع `main` والمجلد `/ (root)`.

لا توجد عملية بناء أو تبعيات.
